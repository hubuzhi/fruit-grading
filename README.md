# 基于图像数据的果蔬品质与成熟度智能分级系统

## 一、项目简介

本项目针对农产品分级场景，基于深度学习技术实现果蔬图像的**自动识别与品质评估**。系统联合三个MobileNetV2模型，对输入图片同时输出：水果种类、成熟度等级、品质等级，并给出每个判断的置信度。

最终交付为**单文件HTML应用**（33.9MB），双击即可在浏览器中运行，无需安装任何依赖环境，便于演示和分享。

## 二、数据集

- **来源**：Kaggle Fruit Quality Classification
- **规模**：18452张图片，6种水果（苹果、香蕉、番石榴、青柠、橙子、石榴）
- **划分**：训练集12911张 / 验证集2763张 / 测试集2778张（约7:1.5:1.5）
- **预处理**：统一缩放至224×224，使用ImageNet均值方差归一化；训练时随机水平翻转做数据增强

## 三、方法

### 3.1 整体架构

采用三个独立的MobileNetV2模型分别完成不同任务，共享相同的图像预处理流程：

| 模型 | 任务 | 类别数 | 说明 |
|---|---|---|---|
| 水果识别模型 | 判断图片中是什么水果 | 6类 | 苹果/香蕉/番石榴/青柠/橙子/石榴 |
| 成熟度模型 | 判断水果成熟程度 | 3类 | 未成熟/成熟/过熟腐败 |
| 品质模型 | 判断水果品质等级 | 3类 | A级优等/B级合格/C级残次 |

### 3.2 模型选择

选用MobileNetV2作为骨干网络，主要考虑：
- 参数量小（约3.5M），CPU推理速度快
- ImageNet预训练权重可直接迁移学习
- 适合浏览器端部署（模型文件小，加载快）

### 3.3 训练策略

- 迁移学习：加载ImageNet预训练权重，替换最后的全连接层为对应分类数
- 损失函数：交叉熵（水果模型加入类别权重应对不均衡）
- 优化器：Adam，学习率1e-3
- 训练环境：CPU

## 四、实验结果

### 4.1 测试集总体表现

| 模型 | 准确率 | 说明 |
|---|---|---|
| 水果种类识别（6类） | 99.96% | 修复标签名+类别权重后，2778张测试集仅1张错误 |
| 成熟度分级（3类） | 96.90% | 扩充训练数据至4000张后重训 |
| 品质等级判定（3类） | 89.06% | 扩充训练数据至4000张后重训 |

### 4.2 模型迭代改进过程

项目经历了多轮迭代优化：

1. **初版**：三个模型各用少量数据训练，水果识别准确率84.95%，其中青柠类别准确率为0%
2. **定位问题**：发现代码中标签名写的是"青柠/柠檬"，但数据集中实际标签为"青柠"，导致所有青柠样本匹配失败
3. **修复标签+类别权重**：修正标签名，加入类别权重应对不均衡，水果模型准确率提升至99.96%
4. **扩充数据**：成熟度和品质模型从每类200张扩充至4000张数据重新训练，准确率分别提升至96.90%和89.06%

### 4.3 评估维度

对每个模型均完成以下评估（结果见 `eval/figs/`，共18张图）：

- **混淆矩阵**：展示各类别的正确/错误分布
- **ROC曲线与AUC**：衡量二分类（one-vs-rest）的区分能力
- **PR曲线与AP**：衡量精确率-召回率权衡
- **分水果准确率**：按水果种类分别统计准确率
- **置信度分布**：正确/错误样本的置信度直方图，配合ECE分析校准程度
- **误判图册**：展示置信度最高的错误案例，便于分析误判原因

## 五、系统使用

### 5.1 体验方式

直接双击 `app/果蔬识别系统.html`，在浏览器中打开即可使用。

支持三种图片上传方式：
1. 点击上传区域选择本地图片
2. 直接拖放图片到页面
3. 按 Ctrl+V 粘贴剪贴板中的图片

识别结果会同时展示：水果种类、成熟度等级、品质等级，以及每项判断的置信度。

### 5.2 技术实现

三个PyTorch模型导出为ONNX格式（opset=13兼容浏览器），base64编码内嵌到单个HTML文件中，浏览器端使用onnxruntime-web进行推理，不需要服务器。

## 八、已知局限与改进方向

### 局限
1. 成熟度和品质标签基于颜色特征自动生成（弱监督方式），未经人工标注校正
2. 测试集与训练集来自同一数据集，分布相似，准确率偏高；在域外图片上泛化能力有限
3. A级优等样本占比较少（约7%），存在类别不均衡问题
4. 仅适用于单果特写图像，复杂背景或多果并排场景效果会下降

### 改进方向
1. 补充人工标注数据，提升标签质量
2. 收集更多真实场景图片做领域适配，提升泛化能力
3. 引入果实主体分割，减少背景干扰
4. 对模型进行INT8量化，进一步减小HTML文件体积
5. 尝试更大的骨干网络（如ResNet50）对比实验

## 九、技术栈

- 训练框架：PyTorch
